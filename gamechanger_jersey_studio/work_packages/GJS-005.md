# GJS-005 — Reference Image Management

**Version:** 1.0.0-alpha.5  
**Build:** 005  
**Release date:** 2026-06-30

## Delivered

- Reference image model and manifest (`references/manifest.json`)
- Image bytes persisted in `.gjs` at `references/images/`
- Import: PNG, JPEG, TIFF, WEBP, PSD (flattened)
- Metadata: ID, filename, dimensions, checksum, colour profile, orientation
- Multi-tag categories (12 types)
- Card-based Reference Images page with drag-and-drop import
- Full-screen image viewer with zoom and navigation
- Workspace thumbnails (`reference_thumbnails/`)
- Dashboard: imported count, required/missing categories, resolution, preview
- Explorer: All Images, Front/Rear/Details, Uncategorised, Validation
- Operations: import, replace, delete, duplicate, rotate, rename, retag, reveal
- History and logging for all image events
- 58 tests passing
