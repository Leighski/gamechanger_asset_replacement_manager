# GJS-004 — Design Specification Engine

**Version:** 1.0.0-alpha.4  
**Build:** 004  
**Work package:** GJS-004 / EPIC 3 Build 004  
**Release date:** 2026-06-30

## Objective

Create the permanent Design Specification subsystem — the canonical data model for every jersey project. No AI, Photoshop, or PSD generation.

## Delivered

### Data model
- `models/design_specification.py` — full Pydantic schema with all editable properties
- Stored at `design/specification.json` inside `.gjs`
- Backward compatible with projects created before Build 004

### Services
- `services/design_specification_service.py` — apply changes, history, logging
- `services/design_spec_validation.py` — live validation rules
- `services/design_spec_completion.py` — completeness scoring
- `services/design_spec_undo.py` — undo/redo command stack
- `services/design_catalogue_service.py` — JSON catalogue loading

### Catalogues (`config/catalogues/`)
- collars, patterns, sleeves, materials, effects, output_profiles

### UI
- `ui/widgets/design_specification_editor.py` — grouped panel editor
- Sidebar **Design** (Ctrl+2) shows editor
- Dashboard completeness score panel
- Project Explorer Design Specification sections with validation icons
- Edit → Undo/Redo wired to specification changes
